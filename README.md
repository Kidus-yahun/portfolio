# K_D — Animated Developer Portfolio 🚀

> High-performance, kinetic developer portfolio built with React 19, Tailwind CSS, GSAP, and WebGL2.

![Portfolio Banner](/public/hero_center.png)

## ✨ Features

- **Kinetic "Ballista" Preloader**: Dropping physics dot, recoil cannon barrel aiming, ballistic letter trajectory animations, and real-time scramble decoding.
- **WebGL2 Particle Mosaic**: Samples portrait photo onto the GPU as thousands of floating tiles, with interactive cursor repulsion and 3D scroll explosion.
- **Word-by-Word Scroll Light-up Bio**: High-end reading animation where words sequentially illuminate as you scroll down.
- **Smart Auto-Hide Sticky Header**: Seamlessly glides offscreen on scroll down, and slides back into view when scrolling up or touching the top 60px of the screen.
- **Red & Black Toolchain**: Custom dark ceramic cards with official tool SVGs, neon red halos, and magnetic cursor suction.
- **"Ricochet" Playable Headline Game**: Embedded canvas brick-breaker mini-game where a bouncing neon ball shatters typography blocks.
- **Case Studies Showcase**: Interactive project list with floating screenshot previews tracking cursor inertia.
- **Full-Stack Cybersecurity Profile**: Real project integrations (Anti-Phish, Ethio-Matrix, SmartBus, Anser Multimodal Solver).

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS 3.4
- **Animation Engine**: GSAP 3.12
- **Shaders & 3D**: WebGL2 Canvas (GLSL)
- **Icons**: Lucide Icons + Custom SVGs

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Kidus-yahun/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 📦 Build for Production

```bash
npm run build
```

The optimized static assets will be output to the `dist/` folder.
